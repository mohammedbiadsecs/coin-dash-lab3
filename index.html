LAB 3 · STARTER GAME

Coin Dash

Collect yellow coins and grab magenta stars for a speed boost. Dodge red drones.

Choose a difficulty, then start the round.

Move: arrow keys / WASD · Pause: P · Restart: R · Changing difficulty takes effect next round.

GAME GUIDE

How to Play

Collect as many coins as you can before time runs out, without touching a red drone.

  • MoveWASD or the Arrow Keys
  • Pause / ResumePress P
  • RestartPress R
  • DifficultyChoose Easy, Normal, or Hard before a round. Harder modes add more, faster drones.
  • Yellow coinsCollect them to increase your score.
  • Pink starGrab it for a temporary speed boost.
  • Best scoreYour record is saved in this browser and persists between visits.
